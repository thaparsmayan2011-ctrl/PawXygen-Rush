# PawXygen-Rush
PawXygen Rush is a grid puzzle game built with HTML5 Canvas and  JavaScript. You play as Laika the space dog, and navigate through different puzzles to help her escape and come back home!



**How to Play**
Objective
You must navigate through each maze to find the Access Key.  


Then finally unlock and reach the Exit Door before running out of oxygen.  

Evade security traps.  

 
 Controls
WASD and Arrow keys
Up: "W"/ "Arrow Up"
Right: "D"/ "Arrow Right"
Left: "A"/ "Arrow Left"
Down: "S"/ "Arrow Down"

 Game Elements
Laika (Player): Our hero.  

 Oxygen Tank (+10): Refills 10 units of your oxygen.  

 Access Key: Needed to unlock the exit door.  


 Exit Door: Unlocks when holding the Access Key.  


 Pressure Plate: Toggles active security lasers ON or OFF.  


 Patrol Droid (Hazard): Patrols paths, collision leads to failure!  


 WARNING!
 extract all files before playing. Keep all files in the same folder


 Laser / Firewall (Hazard): Avoid contact when active!  

 Built With
HTML5 Canvas: 2D rendering.  
HTML
Vanilla JavaScript: Game logic.   
Web Audio API
